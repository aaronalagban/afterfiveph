# AfterFivePH - Feature-Sliced Design (FSD) Architectural Mapping

This document maps the current application structure to the Feature-Sliced Design (FSD) methodology. This is intended to help AI agents understand the architectural roles of existing files.

## Overview of FSD Layers
1. **App**: Global initialization (providers, styles, layouts).
2. **Pages**: Route-level components.
3. **Widgets**: Complex UI blocks composed of features and entities (e.g., EventFeed).
4. **Features**: User interactions with business value (e.g., SubmitEvent, ScrapeEvents).
5. **Entities**: Business logic and data models (e.g., Event, Venue, Community).
6. **Shared**: Reusable cross-project logic (UI kit, API clients, helpers).

---

## 1. App Layer (src/app - Global Setup)
- src/app/layout.tsx: Root Layout & Providers
- src/app/globals.css: Global Styles
- src/app/favicon.ico: Assets

## 2. Pages Layer (src/app - Route Components)
- src/app/page.tsx: Home Page
- src/app/communities/page.tsx: Communities Directory
- src/app/communities/[id]/page.tsx: Community Detail Page
- src/app/submit/page.jsx: Event Submission Page
- src/app/admin-queue/page.jsx: Admin Review Queue

## 3. Widgets Layer (src/components/... - Composition)
- src/components/features/events/EventFeed.tsx: EventFeed Widget (Displays events using Entity logic and potentially Feature actions).

## 4. Features Layer (src/features/... - User Actions)
- src/features/scraper/: Scrape Events Feature
  - classifier.ts, image.service.ts, instagram.client.ts, scraper.service.ts, validator.ts, types.ts
- src/components/ManualSubmissionForm.jsx: Submit Event Form (User-facing feature for manual entry).
- src/app/api/scrape/: Scraping API
- src/app/api/submit-event/: Submission API
- src/app/api/admin-action/: Admin Management API

## 5. Entities Layer (src/features/... - Business Logic)
- src/features/events/: Event Entity
  - events.repository.ts, events.service.ts, types.ts
- src/features/venues/: Venue Entity
  - venues.repository.ts, venues.service.ts, types.ts
- src/components/communities/PlanetProfile.tsx: Community Entity UI (Presentation of a community profile).

## 6. Shared Layer (src/lib, src/utils, src/components/ui)
- src/components/ui/: Shared UI Kit (Buttons, inputs, etc.)
- src/lib/: Shared Logic & API Clients
  - supabase-client.ts, supabase-server.ts, supabase.ts: Supabase Integration
  - logger.ts, retry.ts, concurrency.ts: Utilities
- src/types/index.ts: Global Types
- src/utils/manualSubmissionServer.js: Server-side Utils

---

## External (Non-FSD)
- scripts/: Maintenance and database scripts (run-scraper, update-database).
- .github/workflows/: CI/CD (scraper automation).
- Root configs: next.config.ts, tsconfig.json, tailwind.config.ts, etc.
